# Sultans NBA Daily: Draft Report Card

A single static page. No build step.

## Put it on GitHub Pages
1. Create a new public repository named `sultans-draft`.
2. Upload every file in this folder (Add file > Upload files), then commit.
3. Settings > Pages > Build and deployment: Source "Deploy from a branch", branch `main`, folder `/ (root)`. Save.
4. After a minute the site is at `https://YOUR-GITHUB-USERNAME.github.io/sultans-draft/`.
5. For the WhatsApp link preview, open `index.html` on GitHub, click the pencil, and replace
   `YOUR-GITHUB-USERNAME` (it appears twice) with your username. Commit.

Any static host works too (Netlify, Cloudflare Pages, Vercel): upload the folder as-is.
